# My First Blog Post: Getting Started with GitHub

Every project starts with a small step. Today, mine is creating a simple blog post as part of a GitHub tutorial.

As an architect and 3D visualiser, I’m used to turning ideas into visual experiences. Learning GitHub is an opportunity to explore how I can organise projects, document my work, and collaborate with others.

## What I Hope to Learn

- Create a repository for a new project.
- Write and format content using Markdown.
- Save changes with clear commit messages.
- Explore branches and pull requests.

## Starting Small

For this first exercise, I’m keeping things simple: write a post, make a few edits, and follow how those changes are recorded.

Eventually, I’d like to use these skills to build a portfolio website and share experiments in architectural visualisation and interactive design.

This post marks the beginning. More projects—and lessons—to come!
